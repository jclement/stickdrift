# StickDrift browser host SDK

`host.ts` is published as **https://stickdrift.net/sdk.js** (an ES module)
with its types at **/sdk.d.ts**. A browser game imports it straight from the
relay, so the SDK always matches the relay it talks to.

```js
import { StickDriftHost, pressed, held } from "https://stickdrift.net/sdk.js";

const host = new StickDriftHost({ title: "My Game", look: { layout: "dpad-ab" } });
host.on("open", (code, joinUrl) => showQr(joinUrl));
host.on("join", (pad) => host.setPad(pad.pad, { label: `PLAYER ${pad.pad + 1}`, color: "#e63946" }));
host.on("leave", (pad) => removePlayer(pad.pad));

function frame() {
  for (const [n, p] of host.poll()) {      // once per frame
    if (pressed(p, "A")) jump(n);          // went down since the last poll, however briefly
    if (held(p, "Left")) walkLeft(n);
    steer(n, p.state.lx);                   // sticks and sliders, -1..1
    badge(n, p.p2p ? "P2P" : "relay", p.rtt);
  }
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
```

A complete game is [`examples/web-pong`](../../../examples/web-pong).

- **Events:** `open`, `join`, `leave`, `input`, `rtt`, `p2p`, `close`, `error`
  (`"replaced"` when another host takes the room with this key).
- **Commands:** `setLook`, `setPad` (merged over the pad's look), `haptic`,
  `kick`, `setOpen`, `close`.
- **P2P first.** Phones offer WebRTC data channels; the host answers, and
  input arrives in about a millisecond on the same Wi-Fi, over the relay
  otherwise. `pad.p2p` and the `p2p` event say which.
- **Reconnects** keep pads seated and P2P channels open; relay-only pads are
  released until the relay is back, and the welcome is reconciled (`leave` for
  anyone gone). Save `host.code` and `host.key` to reclaim a room after a
  reload.
- `ControllerHost` is a deprecated alias of `StickDriftHost`.

**TypeScript:** download `/sdk.d.ts` and map the URL to it in `tsconfig.json`:
`"paths": { "https://stickdrift.net/sdk.js": ["./sdk.d.ts"] }`. It is
generated by `scripts/sdk-dts.ts` during `mise run build`. Tests:
`test/client/sdk.test.ts` (fake sockets and peers, in vitest).
